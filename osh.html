إدارة السلامة والسياسات

نظام الإدارة

سياسة OH&S · أهداف · أدوار · مشاركة العمال · مؤشرات أداء · مراجعة الإدارة.

ISO 45001

PDCA: خطط → نفّذ → افحص → حسّن. التكامل مع الجودة والبيئة ممكن لاحقاً.

ثقافة الوقاية

قيادة ظاهرة، إبلاغ بلا عقاب غير عادل، وتعلّم من الوشيك قبل الحادث.

تقييم المخاطر

  1. تحديد الأخطار — HAZID / جولات / تحليل مهام
  2. تقييم — احتمال × شدة (مصفوفة)
  3. خطة تحكم — وفق التسلسل الهرمي
  4. سجل المخاطر — ملكية، موعد مراجعة، حالة
  5. JSA / JHA — خطوة بخطوة قبل التنفيذ

فئات الأخطار

كل فئة تتطلب ضوابط مناسبة — لا تعتمد على PPE وحدها.

التسلسل الهرمي للتحكم → PPE

1–4 قبل PPE

  • إزالة
  • استبدال
  • تقنية
  • إدارية

أنواع PPE

  • رأس / عين / سمع
  • تنفس / يد / قدم
  • سقوط / ملابس واقية
