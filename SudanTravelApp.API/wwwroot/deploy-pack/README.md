# ودنوح AAMN للبرمجيات والكمبيوتر - AAMN

## نظرة عامة

موقع ويب احترافي كامل لـ **ودنوح AAMN للبرمجيات والكمبيوتر (AAMN)** — تصميم عصري ومتطور باللغة العربية مع دعم RTL كامل، يشمل 5 صفحات رئيسية ولوحة تحكم لإدارة الرسائل.

---

## 🌐 صفحات الموقع

| الصفحة | المسار | الوصف |
|--------|--------|-------|
| الرئيسية | `index.html` | الصفحة الرئيسية مع Hero، الخدمات، الأعمال، الشهادات |
| من نحن | `about.html` | قصة الشركة، الرؤية والرسالة، الفريق، الاعتمادات |
| الخدمات | `services.html` | عرض تفصيلي لجميع الخدمات ومراحل العمل |
| الأعمال | `projects.html` | معرض الأعمال مع فلتر حسب النوع |
| تواصل معنا | `contact.html` | نموذج التواصل وبيانات الاتصال وخريطة Google Maps |
| **لوحة التحكم** | `admin.html` | إدارة الرسائل الواردة (جديدة/مقروءة/تم الرد/حذف) |

## ✅ الميزات المكتملة

### التصميم
- ✅ تصميم احترافي عصري مع هوية بصرية قوية (ذهبي + أزرق داكن)
- ✅ دعم RTL كامل مع خطوط عربية (Cairo, Tajawal)
- ✅ تصميم متجاوب (Responsive) لجميع أحجام الشاشات
- ✅ Preloader مع أنيميشن احترافي في **جميع الصفحات**
- ✅ شريط تنقل ثابت مع تأثير التمرير
- ✅ قائمة جانبية للجوال

### الصفحة الرئيسية
- ✅ قسم Hero بخلفية ديناميكية مع جسيمات متحركة
- ✅ عداد أرقام الإحصائيات المتحرك
- ✅ قسم "من نحن" مختصر
- ✅ شبكة الخدمات (6 خدمات)
- ✅ قسم "لماذا نحن" مع رسوم متحركة دائرية
- ✅ معرض الأعمال مع فلتر تفاعلي
- ✅ شريط إحصائيات
- ✅ سلايدر تقييمات العملاء
- ✅ شريط الشركاء المتحرك
- ✅ قسم CTA احترافي
- ✅ Footer شامل

### التفاعلية
- ✅ أنيميشن Scroll Reveal للعناصر
- ✅ فلتر الأعمال بالفئات
- ✅ سلايدر تقييمات بأزرار تنقل ونقاط
- ✅ زر العودة للأعلى (يسار)
- ✅ زر WhatsApp عائم (يمين) — **تم إصلاح موضعه**
- ✅ نموذج تواصل مع التحقق من الصحة

### صفحة التواصل
- ✅ نموذج تواصل احترافي مع حفظ تلقائي في قاعدة البيانات
- ✅ خريطة Google Maps مدمجة وتفاعلية
- ✅ أزرار "احصل على الاتجاهات" و"واتساب مباشر"

### لوحة تحكم الرسائل (admin.html) — جديد
- ✅ Sidebar احترافي مع روابط للصفحات
- ✅ إحصائيات سريعة: إجمالي / جديدة / مقروءة / تم الرد
- ✅ جدول شامل لعرض جميع الرسائل
- ✅ فلترة حسب الحالة (كل / جديدة / مقروءة / تم الرد)
- ✅ بحث بالاسم أو البريد أو محتوى الرسالة
- ✅ Pagination للرسائل الكثيرة
- ✅ عرض تفاصيل الرسالة في Modal
- ✅ تعيين رسالة كـ"مقروءة" تلقائياً عند الفتح
- ✅ تعيين رسالة كـ"تم الرد"
- ✅ رد مباشر بالبريد الإلكتروني
- ✅ حذف الرسائل مع تأكيد

### قاعدة البيانات
- ✅ جدول `contact_messages` لحفظ رسائل التواصل

## 🗄️ نماذج البيانات

### جدول `contact_messages`
| الحقل | النوع | الوصف |
|-------|-------|-------|
| id | text | معرف فريد |
| name | text | اسم المرسل |
| email | text | البريد الإلكتروني |
| phone | text | رقم الجوال |
| service | text | نوع الخدمة المطلوبة |
| message | rich_text | محتوى الرسالة |
| status | text | حالة الرسالة (new/read/replied) |
| submitted_at | datetime | تاريخ الإرسال |
