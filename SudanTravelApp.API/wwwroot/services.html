هندسة البرمجيات وبايثون والذكاء الاصطناعي

نطور حلولاً برمجية متقدمة تعتمد على لغة بايثون (Python) الأساسية في الأتمتة والذكاء الاصطناعي وعلوم البيانات، بالإضافة إلى حزمة اللغات (JavaScript, C#, PHP, C++, SQL) لكافة منصات الويب والموبايل والأنظمة المؤسسية.

  • أتمتة الأعمال ومعالجة الملفات والبيانات بلغة Python
  • نماذج التنبؤ والذكاء الاصطناعي وخوادم FastAPI
  • تطبيقات الويب المتجاوبة ولوحات التحكم (React & Node.js)
  • أنظمة سطح المكتب والمؤسسات بلغة C# .NET
  • برمجة المتحكمات المدمجة والـ IoT بلغة MicroPython & C++
