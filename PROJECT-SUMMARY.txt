🏛️ المعالم التقنية الرئيسية:

  1. أهرامات مروي - آثار نوبية قديمة
  2. متحف السودان القومي - كنوز أثرية
  3. البحر الأحمر - شواطئ ومواقع غوص
  4. ملتقى النيلين - النيل الأزرق + الأبيض
  5. سوق أم درمان - أكبر سوق تقليدي
  6. جبل البركل - معابد فرعونية

🔌 نقاط نهاية API الرئيسية:

  Flights:
    GET  /api/flights
    GET  /api/flights/search?from=...&to=...
    POST /api/flightbookings

  Hotels:
    GET  /api/hotels
    GET  /api/hotels/search?city=...&minRating=...
    POST /api/hotelbookings

  Tourism:
    GET  /api/touristattractions
    GET  /api/touristattractions/city/{city}

  Bookings:
    GET  /api/flightbookings/reference/{ref}
    GET  /api/hotelbookings/reference/{ref}
    PUT  /api/flightbookings/{id}/cancel
    PUT  /api/hotelbookings/{id}/cancel
