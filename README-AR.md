## 📖 نظرة عامة

**ود نوح للبرمجيات والكمبيوتر** هي منصة رقمية هندسية وتقنية متكاملة مخصصة للحلول البرمجية، صيانة الحاسوب والشبكات، الأنظمة الذكية، والتعليم الهندسي والتقني في السودان والوطن العربي.

* **الشعار:** برمجة • صيانة • تواصل • دعم *(Code • Repair • Connect • Support)*
* **الدومين الرسمي:** [https://2-aa.com](https://2-aa.com)
* **الدومين السابق:** `wadnooh.com` (تم تحويله بالكامل عبر توجيه دائم 301 إلى `2-aa.com`)
* **بيئة التطوير:** ASP.NET Core 10.0 + واجهات ويب تفاعلية حديثة (RTL / عربي)

## ✨ الأقسام والوحدات الرئيسية

### 1. 💻 استوديو ومختبر الأكواد (Code Studio)
* **الملف:** [code-hub.html](file:///e:/FLY/code-hub.html)
* بيئة تشغيل برمجية تفاعلية داخل المتصفح تدعم:
  - **Python Core:** تنفيذ وتجربة سكريبتات بايثون مباشرة.
  - **Web Studio:** محرر HTML / CSS / JavaScript مع معاينة حية لحظية.
* مكتبة نماذج برمجية جاهزة للاستخدام والشرح.

### 2. 🦺 مركز السلامة والصحة المهنية (OSH / HSE Center)
* **الملف:** [osh.html](file:///e:/FLY/osh.html)
* مركز متخصص لإدارة المخاطر وتطبيقات السلامة:
  - مصفوفات تقييم المخاطر (Risk Assessment).
  - تصاريح العمل (Permit to Work - PTW).
  - خطط الطوارئ ومعدات الحماية الشخصية (PPE).
  - مكتبة معايير دولية وروابط معتمدة للمصادر الرسمية.

### 3. ⚙️ البوابات والتخصصات الهندسية (Engineering Specialties)
* **الملف:** [specialty.html](file:///e:/FLY/specialty.html)
* بوابات تفاعلية تغطي أكثر من 22 تخصصاً هندسياً وتقنياً (برمجيات، شبكات، ميكاترونكس، طاقة، طب حيوي، اتصالات، نفط وتعدين).
* خرائط طريق (Roadmaps)، دورات تدريبية، مراجع علمية، ومشاريع تخرج ونماذج تطبيقية.

### 4. 👤 بوابة العملاء والدعم الفني (Client Portal)
* **الملف:** [client.html](file:///e:/FLY/client.html)
* لوحة تحكم للعملاء لمتابعة:
  - طلبات البرمجة وتطوير المواقع والتطبيقات.
  - تذاكر صيانة الكمبيوتر والأجهزة والشبكات.
  - التواصل المباشر مع فريق الدعم الفني وتحديثات الحالة.

### 5. 🛡️ لوحة التحكم والإدارة الموحدة (Admin Dashboard)
* **الملف:** [admin.html](file:///e:/FLY/admin.html)
* نظام إدارة متكامل ومحمي بالمصادقة (JWT / Master Admin):
  - إدارة المحتوى والكتالوجات (الدورات، المشاريع، المقالات، الجامعات).
  - مراقبة النشاط والرسائل وتذاكر الدعم.
  - إعدادات النظام ومزامنة قواعد البيانات.

### 6. 🎓 نظام التحقق من الشهادات (Certificate Verification)
* **الملف:** [verify.html](file:///e:/FLY/verify.html)
* فحص وتأكيد صحة وموثوقية الشهادات الصادرة عبر الرقم التسلسلي أو رمز الاستجابة السريعة (QR Code).

## 🚀 التشغيل المحلي السريع

### الطريقة 1: استخدام سكريبتات التشغيل (موصى بها)
**عبر PowerShell:**
```powershell
.\RUN.ps1
```

**عبر موجه الأوامر (CMD):**
```cmd
RUN.bat
```

### الطريقة 2: عبر .NET CLI
```powershell
cd SudanTravelApp.API
dotnet restore
dotnet run
```

يفتح التطبيق تلقائياً على المنفذ الافتراضي في المتصفح.

## 🌐 النشر على Hostinger والدومين الجديد 2-aa.com

1. تم إعداد الدومين الجديد بالكامل: **[https://2-aa.com](https://2-aa.com)**.
2. تم توليد حزمة النشر الجاهزة لمدير الملفات (Hostinger File Manager):
   `publish/2-aa-hostinger-public_html.zip`
3. لرفع الموقع:
   - افتح [hPanel](https://hpanel.hostinger.com) ➔ **Websites** ➔ **2-aa.com** ➔ **File Manager**.
   - ادخل إلى مجلد `public_html`، وارفع الملف المضغوط وفك الضغط داخل المجلد مباشرة.
4. تم ضبط التوجيه التلقائي الدائم (301) من `wadnooh.com` إلى `2-aa.com`.
